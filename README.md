# 🖩 Calculadora Web - Actividad 3

Este proyecto consiste en una calculadora funcional desarrollada con tecnologías web básicas: **HTML, CSS y JavaScript**.

## 📝 Descripción
Se trata de una calculadora simple que permite realizar operaciones matemáticas básicas como suma, resta, multiplicación y división. Tiene un diseño inspirado en las calculadoras clásicas de marca Casio, con una interfaz amigable y fácil de usar.

## 📁 Estructura del Proyecto
## 🚀 Cómo Usar
1. Descarga o clona este repositorio
2. Abre el archivo `index.html` en cualquier navegador web
3. ¡Comienza a calcular!
